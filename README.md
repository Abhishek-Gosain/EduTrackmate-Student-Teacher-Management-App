EduTrackmate — Student & Teacher Management App
EduTrackmate is an Android mobile application designed to support academic management by bringing student and teacher functionalities into a single platform. It provides dedicated Teacher and Student zones to help organize academic activities, manage attendance, access assignments, review results, and view educational resources.

This repository showcases the application through screenshots and project documentation.

📱 Application Screenshots
The application’s interface is showcased in the screenshots/ directory.

Teacher Zone
The Teacher Zone provides access to academic and classroom management features.

Teacher Dashboard: Access to teacher-related functions.
Teacher Profile: View teacher profile information.
Timetable: Access timetable information.
Attendance Marking: Support for recording student attendance.
Assignment Upload: Upload assignments for students.
Student Zone
The Student Zone provides students with access to academic information and learning resources.

Student Dashboard: Access student-related functions.
Result Average: View academic result and average-related information.
Fee Structure: Access information about academic fees.
Assignments & Study Material: Access assignments and educational resources.
Student Profile: View student profile information.
